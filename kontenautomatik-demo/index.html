Schülerkonten und Klassenteams automatisch anlegen

Das PowerShell-Skript liest den Export der Schülerliste, legt Konten in Entra ID an, weist Lizenz und Gruppe zu und erstellt je Klasse ein Team mit der Vorlage Kurs. Hier läuft ein Testlauf mit erfundenen Daten im Browser.

Auszug aus dem Skript

Benutzername aus Vor- und Nachname, Umlaute umgeschrieben, doppelte Namen bekommen eine Ziffer:

function Get-Benutzername([string]$vor, [string]$nach) {
    $s = "$vor.$nach".ToLower()
    foreach ($p in @{ 'ä'='ae'; 'ö'='oe'; 'ü'='ue'; 'ß'='ss' }.GetEnumerator()) { $s = $s.Replace($p.Key, $p.Value) }
    return ($s -replace '[^a-z0-9.\-]', '')
}

Konto anlegen nur, wenn nicht im Testlauf (SupportsShouldProcess, -WhatIf):

if ($PSCmdlet.ShouldProcess($upn, 'Konto anlegen')) {
    $u = New-MgUser -AccountEnabled -DisplayName "$($s.Vorname) $($s.Nachname)" `
        -UserPrincipalName $upn -EmployeeId $s.Schuelernummer -Department $s.Klasse `
        -PasswordProfile @{ Password = $pw; ForceChangePasswordNextSignIn = $true }
    Set-MgUserLicense -UserId $u.Id -AddLicenses @(@{ SkuId = $cfg.LizenzSkuId }) -RemoveLicenses @()
}

Klassenteam mit der Vorlage Kurs:

$body = @{
    'template@odata.bind' = "https://graph.microsoft.com/v1.0/teamsTemplates('educationClass')"
    displayName = "Klasse $($k.Klasse) 2026/27"
    members = @(@{ '@odata.type' = '#microsoft.graph.aadUserConversationMember'; roles = @('owner')
                   'user@odata.bind' = "https://graph.microsoft.com/v1.0/users('$lehrkraft')" })
}
New-MgTeam -BodyParameter $body
